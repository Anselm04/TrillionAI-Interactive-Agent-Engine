# Procedural avatar renderer
This branch introduces actual XYZ vertices, indexed triangles, 3D rotations, perspective projection, face culling, directional shading and depth sorting in Flutter Canvas. Aura and Nova are original procedural character definitions with independently deformable eyes and mouth. This is a CPU-rendered opaque mesh prototype, not a GPU rasterizer: painter ordering is approximate and complex intersecting geometry is not supported. No external model download or paid service is needed. GLB import, textures, skeletal animation, accurate viseme timing and hardware acceleration remain outstanding. Qualification requires the mesh unit tests and visual rendering tests; no runtime results are claimed until CI completes.
