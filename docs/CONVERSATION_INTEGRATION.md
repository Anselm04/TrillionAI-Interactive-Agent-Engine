# Local conversation integration
The opt-in memory wrapper adds bounded history to local model prompts and stores completed turns in SQLite. Set ENGINE_MEMORY_PATH explicitly to enable it alongside ENGINE_LOCAL_MODEL. The current local service has one trusted owner and a shared development token; this is not production tenant authentication. Stored data is plaintext at rest. Do not expose the service publicly or use sensitive customer information. Remove the local database when no longer needed. Memory is not enabled by default. Tests use deterministic reasoning and in-memory SQLite.
