# Local development
Node 22+ and Flutter 3.50.0 with Dart 3.14+ are required. No paid API is used. Generate a random token with openssl rand -hex 32, then set ENGINE_TOKEN in your shell. From services/engine run npm test and npm start. The engine binds only to loopback.
From apps/demo_flutter run flutter create --platforms=web --project-name trillionai_interactive_demo . (preserve existing lib and pubspec), flutter pub get, flutter test, then flutter run -d chrome --web-hostname localhost --web-port 8080. Enter the same token in the UI. Browser voice availability varies; microphone recognition can use OS/browser cloud processing. No audio is stored by this application.
The avatar is an original procedural 2D orb with shaded appearance and state animations; it is not a 3D mesh or phoneme-synchronized animation. The default provider echoes text, explicitly labelled. The speech plugins are real platform calls, not a simulated voice, but device qualification is outstanding. The local token is a development-only shared credential, not multi-tenant authentication. Native platform scaffolding, permissions, real model integration, streaming duplex voice and production hardening remain outstanding.
