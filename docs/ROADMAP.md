# Engineering roadmap
All items below are planned, not delivered.
1. Local foundation: reproducible Flutter and Node builds, typed event contracts, linting and CI.
2. Interactive session: authenticated transport, text streaming, cancellation, reconnect and deterministic simulator.
3. Avatar engine: original assets, animation states, visemes and accessible controls.
4. Voice: streaming input/output, interruption, consent and provider-independent adapters.
5. Memory: tenant isolation, retrieval, retention, export and deletion tests.
6. Agents: capability registry, approval gates, execution budgets and audit records.
7. Integrations: independently versioned SDKs; no changes to other repositories without authorization.
8. Commercial readiness: usage metering, billing design, load testing, SDK docs, platform qualification and release security review.
## Acceptance
Each phase requires executable tests, documented evidence, and explicit distinction between simulated and real external integration results. No paid infrastructure or deployment without approval.
