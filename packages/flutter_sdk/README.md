# TrillionAI Interactive SDK
Private Dart package usable from Flutter or Dart. Add a local path dependency to packages/flutter_sdk, import package:trillionai_interactive_sdk/trillionai_interactive_sdk.dart, and construct InteractiveEngineClient with the engine origin and an asynchronous credential callback. Call createSession, sendMessage, deleteSession and close. Remote endpoints require HTTPS. Local demo HTTP is loopback-only. The current engine uses a shared development token, not production tenant identity. Tests use HTTP mocks, not live audio or model services. Run dart pub get, dart analyze and dart test in this directory.
